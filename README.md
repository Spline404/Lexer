Lexer and Parser in Python

A simple lexer and parser implemented in Python.

The lexer tokenizes the input source code into a sequence of tokens, while the parser analyzes these tokens according to the defined grammar and builds an abstract syntax tree (AST).

Features
		Lexical analysis and tokenization
		Syntax analysis
		Custom grammar
		Abstract Syntax Tree (AST)
		Written entirely in Python
Project Structure
		.
		├── lexer.py      # Converts source code into tokens
		├── parser.py     # Parses tokens according to the grammar
		├── ast.py        # AST node definitions
		└── main.py       # Example usage
Getting Started

Clone the repository and run:

python main.py
Purpose

This project was created to understand how programming language lexers and parsers work and how source code is transformed into a structured representation.
